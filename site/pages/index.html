Fast downloads that pick up where they left off

Vibe splits every file across up to 32 connections, resumes after crashes, reboots and dropped Wi‑Fi, and saves the video streams your browser plays. It's free, open source and built in Rust.

What Vibe does

Everything a download manager should do, in a small native app that starts instantly and stays out of your way.

Speed

Many connections per file
Up to 32, with pieces that split again as connections finish.
Resume anything
Pause, crash, reboot or lose the network: the download continues from the last byte. Vibe checks the file hasn't changed on the server first.
Queues and schedules
Group downloads into queues that run overnight or on weekends, each with its own speed and how many run at once. When a queue is done, Vibe can put the computer to sleep or shut it down.
HTTP, HTTPS and FTP
Including FTP resume, proxies (HTTP and SOCKS5) and site logins.

Video

HLS and DASH streams
Saves .m3u8 and .mpd streams: picks the quality, downloads the segments in parallel and decrypts AES-128.
One file at the end
Audio and video are joined into a single .mp4 when ffmpeg is installed.

Your browser

Takes over downloads
The extension for Chrome, Edge, Brave and Firefox hands files to Vibe with the right cookies and referrer, so logged-in downloads work.
Videos on the page
The toolbar button lists the streams the current page plays. One click sends them to Vibe.

Everyday use

Sorted for you
Files land in folders by type, and the sidebar filters by state and category.
Bulk actions
Select many downloads and pause, resume, open or delete them together.
Columns your way
Resize, reorder, hide or auto-fit the list's columns.
See inside a download
The details panel shows each piece filling as its connection writes, a speed graph, what the server reported and a log of what happened.
Quietly there
Starts minimized with Windows if you like, lives in the tray and notifies you when files finish.
Safe by default
Verify MD5 or SHA checksums, and run a virus scan after each download.
