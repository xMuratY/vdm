Questions and answers

Is Vibe really free?

Yes. It's open source under the MIT or Apache 2.0 license: no price, no trial, no ads and no paid tier.

Why are downloads faster?

Many servers limit the speed of each connection. Vibe opens several connections to the same file, each fetching a different piece, and keeps them all busy by splitting the remaining work as pieces finish. On a fast line that often multiplies the speed. Read how it works.

What happens if my connection drops or my PC restarts?

Vibe saves progress as it goes. When you resume, it checks that the file on the server hasn't changed and continues from the last byte it wrote. If the file did change, it starts over rather than giving you a broken file.

Can it download videos?

It downloads HLS (.m3u8) and DASH (.mpd) streams that a page plays, including AES-128 encrypted ones, and joins them into one file with ffmpeg. It doesn't break DRM. Only download videos you have the right to save.

Which browsers work with it?

Chrome, Edge, Brave and other Chromium browsers, and Firefox 115 or later, through the Vibe extension.

Does Vibe collect any data?

No. There's no account, analytics or telemetry. The only network requests it makes are your downloads and, if you leave it on, a daily check for updates.

Why does Windows warn about the installer?

SmartScreen warns about installers that aren't code-signed by a known publisher yet. The source code is public and the release is built by GitHub Actions from it. Choose "More info", then "Run anyway".

Does it need administrator rights?

No. Vibe installs into your own user folder, which also lets updates install silently.

Does it work on macOS or Linux?

It builds and runs from source on both. Ready-made packages are on the roadmap.

How can I help?

Report bugs and ideas on GitHub, improve a translation, or send a pull request. Telling a friend helps too.
